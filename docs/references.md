# Learning references and provenance

- Google / Coursera: [Using Python to Interact with the Operating System](https://www.coursera.org/learn/python-operating-system). Learning concepts: text files, command-line arguments, regular expressions, dictionaries, environment variables, standard streams, and subprocesses.
- Python standard-library reference: [re](https://docs.python.org/3/library/re.html), [argparse](https://docs.python.org/3/library/argparse.html), [csv](https://docs.python.org/3/library/csv.html), [os](https://docs.python.org/3/library/os.html), [pathlib](https://docs.python.org/3/library/pathlib.html), [subprocess](https://docs.python.org/3/library/subprocess.html), and [unittest](https://docs.python.org/3/library/unittest.html).

The initial implementation, sample dataset, acceptance checks, and learning documents were prepared with ChatGPT assistance for this project. The repository does not redistribute a Coursera lab dataset or reproduce the course's complete solution script.

The implementation applies the learned concepts to a separate CLI: severity filtering is independent of keyword filtering; keyword searches use literal AND matching; outputs include counts and a report; malformed input and operational failures are handled explicitly.

Use `learning_journal.md` to record your own work after running and modifying the project. Do not mark exercises as complete until you have performed them.
